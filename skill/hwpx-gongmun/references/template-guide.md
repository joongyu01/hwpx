# 새 서식 등록하기

부서마다 결재표·표지·장 제목 모양이 다르다. 생성기는 서식 파일 안에 심어둔 **자리표시자**와 **원형 문단**만 보고 동작하므로, 어떤 hwpx든 아래 규칙대로 준비하면 쓸 수 있다.

## 서식이 갖춰야 할 것

서식 hwpx의 본문은 두 부분으로 나뉜다.

1. **머리 부분.** 결재표, 표지, 머리띠처럼 문서마다 한 번 나오는 곳이다. 바뀌는 글자 자리에 `{{TITLE}}` 같은 자리표시자를 넣는다.
2. **원형 부분.** `{{PROTOTYPES}}`라는 글자가 든 문단 한 줄을 넣고, 그 아래에 복제용 원형 문단을 하나씩 둔다. 이 부분은 결과 문서에는 나오지 않는다.

원형은 안에 든 자리표시자로 구분한다. 순서는 상관없다.

| 원형 | 들어갈 글자 | 필수 |
|---|---|---|
| 장 제목 | `{{SEC_NUM}}`과 `{{SEC_TITLE}}` | 예 |
| 빈 줄 | `{{BLANK}}` | 예 |
| □ 라벨 항목 | `({{BOX_LABEL}})`과 `{{BOX_TEXT}}` | 예 |
| □ 라벨 없는 항목 | `{{PLAIN}}` | 선택 |
| ㅇ 하위 항목 | `ㅇ {{SUB}}` | 선택 |
| * 각주 | `* {{NOTE}}` | 선택 |
| 줄글 | `{{PARA}}` | 선택 |
| 표 | 머리칸 `{{TH}}`, 첫 열 `{{TD_KEY}}`, 일반칸 `{{TD}}`, 목록칸 `{{TD_LIST}}` | 표를 쓰려면 |

머리 부분 자리표시자 목록은 `spec.md` 7절에 있다. 목록에 없는 이름도 대문자·숫자·밑줄로 만들면 `fields`로 채울 수 있다.

## 방법 1: 한글에서 직접 만들기 (사람이 할 때)

1. 부서 양식 hwpx를 한글에서 연다.
2. 제목, 부서명, 날짜, 결재자 이름 자리의 글자를 지우고 자리표시자를 입력한다. 예: `{{TITLE}}`.
3. 본문 내용은 모두 지운다. 맨 끝에 `{{PROTOTYPES}}` 한 줄을 쓴다.
4. 그 아래에 원하는 모양대로 원형을 하나씩 만든다. 장 제목 상자를 하나 복사해 번호 자리에 `{{SEC_NUM}}`, 제목 자리에 `{{SEC_TITLE}}`을 쓰는 식이다.
5. hwpx로 저장한다.

자리표시자는 **한 번에 입력하고 중간에 서식을 바꾸지 않는다.** `{{TI`까지 쓰고 굵게 한 뒤 `TLE}}`를 쓰면 글자가 둘로 쪼개져 저장되어 생성기가 찾지 못한다. 서식은 자리표시자 전체를 선택해 한꺼번에 바꾼다.

## 방법 2: Claude가 만들기 (실제 문서만 있을 때)

사용자가 내용이 채워진 결재 문서 한 부만 준 경우다.

1. 문단 구조를 본다.
   ```bash
   node scripts/inspect.js 원본.hwpx
   ```
   각 줄에 문단 번호, 문단모양 번호, 글자모양 번호, 표·그림 여부, 글자가 나온다.
2. 머리 부분이 어디서 끝나는지 정한다. 보통 요약 상자 다음, 첫 장 제목 앞이다.
3. 원형으로 쓸 문단 번호를 고른다. 장 제목 표, □ 항목, * 각주, 빈 줄, 표가 하나씩 필요하다. XML이 궁금하면 번호를 붙여 다시 실행한다.
   ```bash
   node scripts/inspect.js 원본.hwpx 20 44
   ```
4. 일회용 Node 스크립트를 써서 서식을 만든다. 저장소의 `tools/make-template.js`가 그대로 참고할 실제 예시다. 핵심 동작은 다음과 같다.
   - `core.unzip`으로 풀고 `core.topParagraphs`로 문단을 나눈다.
   - 머리 부분의 `<hp:t>실제글자</hp:t>`를 `<hp:t>{{자리표시자}}</hp:t>`로 바꾼다. 결재자 실명, 본문 내용이 남지 않았는지 검사한다.
   - `{{PROTOTYPES}}` 문단과 원형 문단들을 이어 붙인다. 원형은 고른 문단 XML에서 글자만 자리표시자로 바꾼 것이다.
   - `Contents/content.hpf`의 제목과 설명(추적 정보가 들어 있을 수 있다)을 비운다.
   - `core.zip`으로 다시 묶는다. `mimetype`이 맨 앞에 무압축으로 들어가야 한다.
5. 확인한다.
   ```bash
   node scripts/inspect.js 새서식.hwpx
   node scripts/build.js examples/good-station.json --template 새서식.hwpx -o 시험.hwpx
   ```
   첫 줄에 "생성기용 서식입니다"가 나와야 한다. 한글이 있으면 `hwp-preview.ps1`로 시험 문서를 열어본다.

## 주의

- 문단모양·글자모양 번호를 새로 지어내지 않는다. 원본에 있는 문단을 복제해야 번호가 `header.xml`과 맞는다. 새 모양이 꼭 필요하면 `header.xml`의 기존 `hh:paraPr`를 복제해 새 번호를 주고 `itemCnt`를 1 올린다. `tools/make-template.js`의 ㅇ 항목 처리가 그 예다.
- 원본 문서에 사내 로고 그림이 있으면 서식에도 그대로 남는다. 외부에 공유할 서식이면 사용자에게 알린다.
