공문 hwpx 생성기

문서 유형을 고르고 AI가 쓴 내용을 붙여넣으면 결재표·표지·개조식 서식이 갖춰진 한글 파일이 만들어집니다. 모든 처리는 이 브라우저 안에서만 이뤄집니다.

1문서 유형 고르기

장(章) 구성은 기관이 달라도 거의 같습니다. 국가공무원인재개발원 보고서 작성 교재와 부처 계획서 목차를 바탕으로 정리한 12가지 유형입니다.

2AI에게 보낼 요청문 만들기

쓰고 싶은 내용과 참고 자료를 적고 복사하세요. 고른 유형의 장 구성, 작성 규칙, JSON 형식이 함께 복사됩니다. ChatGPT·Claude·Gemini 어디에 붙여넣어도 됩니다.

유형을 고르지 않으면 AI가 알맞은 구성을 정합니다.

3AI가 준 JSON 붙여넣기

AI 답변 중 JSON 부분을 붙여넣으세요. 앞뒤 설명이나 ``` 표시가 섞여 있어도 알아서 걸러냅니다.

4한글 파일 내려받기

파일 이름은 "(부서)제목_날짜시각" 형식으로 자동으로 정해집니다.

우리 부서 서식 쓰기

이 생성기용으로 준비한 서식 hwpx를 올리면 그 모양으로 만듭니다. 서식 만드는 법은 스킬 폴더의 references/template-guide.md에 있습니다.

미리보기

구성을 확인하는 용도입니다. 실제 모양은 한글에서 확인하세요.
문서 유형을 고르고 "빈 틀 불러오기"를 누르거나, AI가 준 JSON을 붙여넣으면 여기에 문서 구성이 보입니다.
